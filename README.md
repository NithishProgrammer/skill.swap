# Recipro Skills

**Recipro Skills** is a user-driven, peer-to-peer "knowledge marketplace" where learners swap skills instead of paying for courses. The platform operates on a simple but powerful philosophy: *“Teach me Python, and I’ll teach you Guitar.”* It aims to create an accessible, community-driven education system where users can teach what they know and learn what they need.

## 🚀 Key Features

- **Skill Swapping:** Connect with like-minded individuals to exchange expertise (e.g., Cooking for Yoga, Public Speaking for Web Design).
- **Integrated Learning Environment:** Use the built-in **VidRooms** for live sessions or connect via preferred external platforms.
- **Course Creation:** Anyone can become an instructor. Create custom course topics, set timings, and manage student applications.
- **Pre-defined Syllabi:** Access curated syllabi for specific topics to ensure high-quality learning outcomes that align with certification standards.
- **Affordable Certification:** Take certification exams for various subjects (like Python or Bio-Diversity) and receive digital certificates via email within minutes of passing.
- **Safety-First Community:** Built-in reporting systems and monitored VidRooms to ensure a transparent and respectful learning environment.

## 🛠️ How It Works

1. **Find a Skill:** Browse popular skill-swap courses or search for specific expertise.
2. **Apply to Swap:** Register for a course. The "Course Maker" (instructor) reviews your application.
3. **Connect & Learn:** Once accepted, use the Dashboard to access meeting links or VidRooms to start your peer-to-peer session.
4. **Get Certified:** After mastering a skill, take an exam on the platform to validate your knowledge.
